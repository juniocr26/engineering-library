## 4. Main priority — independent documentation lifecycle evaluation

The previous planner achieved 22/24 correct decisions on development cases.

That is encouraging, but it does not establish generalization to unseen software.

Build a more rigorous evaluation methodology using source revisions that were not used to design the current decision rules.

Before inspecting the answers:

1. Freeze the current implementation.
2. Freeze evaluation criteria.
3. Record source revisions and provenance.
4. Identify development-family overlap.
5. Separate evaluation material from future training data.
6. Preserve exact source snapshots and expected outputs.
7. Record all tool versions and configuration.

Evaluate:

- ADD.
- MODIFY.
- REMOVE.
- NO-OP.
- INCONCLUSIVE.

Include changes involving:

- Function return values.
- Exceptions and error handling.
- Public signatures.
- Default parameters.
- Configuration.
- Helper dependencies.
- Integration adapters.
- Removed functionality.
- Renamed functionality.
- Refactoring without contract changes.
- Source relocation.
- Documentation that is already correct.
- Insufficient or conflicting evidence.

Distinguish:

- Structural change detection.
- Correct documentation action.
- Correct explanation.
- Correct documentation patch.
- Safe preservation of unaffected content.

A detected source change is not automatically a documentation change.

A missing declaration is not automatically evidence of removal.

A source citation is not automatically proof that a generated claim is correct.

### Evaluation metrics

Measure:

- Exact action accuracy.
- Precision and recall by action.
- False REMOVE rate.
- False MODIFY rate.
- Missed ADD and MODIFY cases.
- Correct NO-OP preservation.
- Appropriate abstention.
- Unsupported factual claims.
- Incorrect cross-file relationships.
- Documentation patch correctness.
- Regression against the previous baseline.

Report denominators and uncertainty.

Do not present development-set performance as independent holdout performance.

If a truly independent family cannot be established, report the limitation and continue with controlled development evaluation.

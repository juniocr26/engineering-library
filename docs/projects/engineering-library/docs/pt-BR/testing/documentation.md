# Validação e limites

[Validador de documentação existente](../../../../../pt-BR/guides/documentation-validator.md).

O scanner atual cobre READMEs e docs/en e docs/pt-BR; não percorre o novo docs/projects. A validação desta coleção deve também conferir links, equivalência de caminhos e alcance dos índices de projeto. Testes Rails existentes verificam /up, não divulgação da senha e SELECT 1; foram inspecionados, sem execução. Lint, typecheck e build do frontend não provam navegação de catálogo implementada.

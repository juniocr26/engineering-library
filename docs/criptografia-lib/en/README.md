# Criptografia Lib

[English](README.md) | [Português brasileiro](../pt-br/README.md)

Composer library for PHP >=8.1 and OpenSSL. `CriptoLib\Crypto` encrypts and decrypts strings; `Configuration` validates constructor inputs. Applications own key custody, authorization, persistence and transport. The Laravel consumers pin package 1.1.3.2 in their manifests; the checkout is evidence of this library, not proof of installed package contents.

Private installation. Current source, executed isolated checks, historical evidence and planned work are distinguished. No production/provider acceptance is claimed.

# Criptografia Lib

[English](../en/README.md) | [Português brasileiro](README.md)

Biblioteca Composer para PHP >=8.1 e OpenSSL. `CriptoLib\Crypto` cifra e decifra strings; `Configuration` valida as entradas do construtor. As aplicações respondem por custódia de chave, autorização, persistência e transporte. Os consumidores Laravel fixam o pacote 1.1.3.2 nos manifests; este checkout evidencia a biblioteca, sem provar o conteúdo instalado.

Instalação privada. Código atual, verificações isoladas executadas, evidência histórica e planejamento são distintos. Não se afirma aceite de produção/provedor.

## Percursos de leitura

Em cada projeto: propósito → arquitetura → fluxo de requisição/evento → dados e integrações → segurança e testes → entrevista. Para avançar entre projetos: env-auditor (arquivos e falhas) → go-image-optimizer (HTTP e recursos) → url-shortener (consistência entre stores) → payment-reconciliation-lab (API/JPA e limites de uma transição) → rust-event-relay (entrega, posse e idempotência). A coleção engineering-library explica o catálogo e o scaffold atual antes das propostas de livro e IA. São sugestões de estudo, não progresso concluído.

A busca futura complementará estas coleções; não existe catálogo independente por assunto, índice de busca ou catálogo recursivo.

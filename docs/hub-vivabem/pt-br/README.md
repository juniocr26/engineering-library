# Hub VivaBem

[English](../en/README.md) | [Português brasileiro](README.md)

Repositório de transporte compartilhado com Redis, RabbitMQ e servidor Socket.IO Node.js em módulos ES. Node encaminha Redis Pub/Sub a destinatários autorizados; RabbitMQ é transporte separado para workers das aplicações. Bancos de domínio e resultados financeiros continuam sob responsabilidade das aplicações.

Instalação privada. Código atual, verificações isoladas executadas, evidência histórica e planejamento são distintos. Não se afirma aceite de produção/provedor.

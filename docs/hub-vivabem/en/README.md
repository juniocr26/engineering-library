# Hub VivaBem

[English](README.md) | [Português brasileiro](../pt-br/README.md)

Shared transport repository containing Redis, RabbitMQ and a Node.js ES-module Socket.IO server. Node bridges Redis Pub/Sub to authorized recipients; RabbitMQ is a separate transport for application-owned workers. Domain databases and financial outcomes remain application responsibilities.

Private installation. Current source, executed isolated checks, historical evidence and planned work are distinguished. No production/provider acceptance is claimed.

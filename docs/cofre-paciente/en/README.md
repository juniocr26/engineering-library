# Cofre Paciente

[English](README.md) | [Português brasileiro](../pt-br/README.md)

Laravel/MongoDB service for encrypted credit/debit references, conferencing links and ratings. Collections, owner validation, observed deletion and provider-confirmed cleanup have distinct responsibilities.

Private installation. Current source, executed isolated checks, historical evidence and planned work are distinguished. No production/provider acceptance is claimed.

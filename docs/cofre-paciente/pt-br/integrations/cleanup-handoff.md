# Ciclo de referências de cartões

Coleções crédito/débito são separadas. Referências mínimas criptografadas rejeitam campos sensíveis. Exclusão observada protege substituição concorrente; débito/limpeza de expirados em produção exige confirmação do provedor pela Carteira nos caminhos implementados. Limpeza de envelope legado ilegível é ramo distinto. Limites antigos somente de teste não descrevem o estado atual. Código não comprova homologação.

[Current implementation / Implementação atual](../../../../../cofre-paciente/docs/pt-br/architecture/current-implementation.md) · [Tests / Testes](../../../../../cofre-paciente/docs/pt-br/testing/testing.md).

Crédito não faz a checagem adicional de sub implementada no débito. Exclusão manual de crédito não realiza a confirmação no provedor usada pelo débito em produção. Estas diferenças são limitações do código atual, não garantias de autorização equivalentes.

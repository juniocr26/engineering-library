# Cofre Paciente

[English](../en/README.md) | [Português brasileiro](README.md)

Serviço Laravel/MongoDB para referências crédito/débito criptografadas, links de conferência e avaliações. Coleções, titularidade, exclusão observada e limpeza confirmada pelo provedor têm responsabilidades distintas.

Instalação privada. Código atual, verificações isoladas executadas, evidência histórica e planejamento são distintos. Não se afirma aceite de produção/provedor.

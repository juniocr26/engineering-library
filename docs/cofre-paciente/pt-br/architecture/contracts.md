# Interfaces e resultados implementados

Base atual do código: 04/11/2026. O escopo é definido pelas fontes reais, não por nomes de placeholders ou contagens antigas.

Rotas POST com escopo expõem links, referências crédito/débito e avaliações. Coleções crédito/débito são separadas. Autenticação, vínculo do corpo, titularidade delegada débito, validação e exclusão observada protegem fronteiras distintas.

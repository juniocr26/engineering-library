# script-auditoria-envs

[English](../en/README.md) | [Português brasileiro](README.md)

CLI Python de biblioteca padrão para sincronização literal de dotenv e aplicação explícita de propostas. `audit-envs.py` delega a `env_sync.main`. É a ferramenta do ecossistema privado, distinta da coleção de portfólio `env-auditor`. Não analisa uso de variáveis pela aplicação nem testa validade de credenciais.

Instalação privada. Código atual, verificações isoladas executadas, evidência histórica e planejamento são distintos. Não se afirma aceite de produção/provedor.

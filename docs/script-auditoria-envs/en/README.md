# script-auditoria-envs

[English](README.md) | [Português brasileiro](../pt-br/README.md)

Standard-library Python CLI for literal dotenv synchronization and explicit proposal application. `audit-envs.py` delegates to `env_sync.main`. It is the private ecosystem tool and is distinct from the existing `env-auditor` portfolio collection. It does not analyze application variable usage or test credential validity.

Private installation. Current source, executed isolated checks, historical evidence and planned work are distinguished. No production/provider acceptance is claimed.

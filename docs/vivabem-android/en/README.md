# VivaBem Android

[English](README.md) | [Português brasileiro](../pt-br/README.md)

Android Trusted Web Activity package using Android Browser Helper, with native introduction and Firebase notification handling. The browser renders the Portal and owns its web session; this is not a separate native appointment/payment backend. Gradle declares min SDK 23 and compile/target SDK 36.

Private installation. Current source, executed isolated checks, historical evidence and planned work are distinguished. No production/provider acceptance is claimed.

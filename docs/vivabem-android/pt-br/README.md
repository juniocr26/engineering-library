# VivaBem Android

[English](../en/README.md) | [Português brasileiro](README.md)

Pacote Android Trusted Web Activity com Android Browser Helper, introdução nativa e notificações Firebase. O navegador renderiza o Portal e mantém a sessão web; não é backend nativo separado de consultas/pagamentos. Gradle declara SDK mínimo 23 e compile/target 36.

Instalação privada. Código atual, verificações isoladas executadas, evidência histórica e planejamento são distintos. Não se afirma aceite de produção/provedor.

# acesso-servidor

[English](README.md) | [Português brasileiro](../pt-br/README.md)

Bash/Python operational tooling for sequential updates of Hub, Portal, Carteira and Cofre. Keep atualizar_projetos.sh, deployment_guard.py and runtime/crypto-probe.php together. This is deployment coordination, not a business API or an atomic transaction across repositories.

Private installation. Current source, executed isolated checks, historical evidence and planned work are distinguished. No production/provider acceptance is claimed.

# acesso-servidor

[English](../en/README.md) | [Português brasileiro](README.md)

Ferramentas operacionais Bash/Python para atualizar sequencialmente Hub, Portal, Carteira e Cofre. Mantenha atualizar_projetos.sh, deployment_guard.py e runtime/crypto-probe.php juntos. É coordenação de deploy, não API de negócio nem transação atômica entre repositórios.

Instalação privada. Código atual, verificações isoladas executadas, evidência histórica e planejamento são distintos. Não se afirma aceite de produção/provedor.
